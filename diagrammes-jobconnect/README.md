# Diagrammes JobConnect

Ce dossier contient les diagrammes du projet JobConnect, separes du cahier des charges.

## Fichiers

- `00-tous-les-diagrammes.md` : tous les diagrammes dans un seul fichier.
- `01-cas-utilisation.mmd` : diagramme de cas d'utilisation.
- `02-classes.mmd` : diagramme de classes.
- `03-entite-association.mmd` : diagramme entite-association.
- `04-sequence-candidature.mmd` : sequence principale de candidature.
- `05-activite-candidature.mmd` : activite du parcours candidat.
- `06-activite-validation-entreprise.mmd` : activite de validation entreprise.

## Utilisation

Les fichiers sont ecrits en Mermaid. Ils peuvent etre ouverts dans VS Code avec une extension Mermaid, dans GitHub, ou dans un editeur en ligne Mermaid.
